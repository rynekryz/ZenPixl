## Features

- Drag & drop or click to upload
- PNG, JPG, WebP and SVG input
- Scale from 0.25× to 3× with the aspect ratio kept
- Auto checkerboard preview when an image has transparency
- Auto-picks PNG for transparent images
- Live output size and ratio
- Slider with live preview
- Preset chips: None, Small, Medium, Large, X-Large, Circle
- Radius shown in pixels as you go
- Export as JPG, PNG or WebP
- Quality slider for JPEG and WebP (10 to 100%)
- Download button that matches the chosen format
- Reset to start over
- Little toasts on save and reset (the polite kind)
- Material 3
- etc.
